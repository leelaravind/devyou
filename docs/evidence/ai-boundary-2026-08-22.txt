What this does and does not establish.

Establishes: four hostile submissions — direct instruction override, a forged
system turn, an authority claim and an attempt to make the model emit a
different schema — were each returned as *content* with the response schema
intact. Five forbidden tasks throw before a request is built. Moderation assist
correctly flagged a destructive command and a pasted credential.

Does not establish: that the deployed queue consumer works end to end. That
needs a real contribution through the production pipeline, which writes
production data, and is an owner decision rather than a verification step.
It also does not establish resistance to injections nobody thought of — the
corpus is four entries and a model's refusal is a behaviour, not a guarantee.
The structural controls are what hold regardless: ALLOWED_TASKS/FORBIDDEN_TASKS
throw before any request, output_config.format makes the schema a request
parameter rather than an instruction, no tools are passed, and packages/ai
cannot reach the database at all.
